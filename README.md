# FridgePolice

FridgePolice is a roommate food tracking prototype.

## Features

- Add food items
- Request food portions
- Approve food usage
- Consume food
- Mark food spoiled
- Correct missing inventory

## Tech Stack

- React
- JavaScript
- Vite

## Scenarios Handled

1. Prevents double allocation
2. Expires unused approvals
3. Handles duplicate item names
4. Allows inventory correction

## Run Project

npm install
npm run dev

Prototype created for the FridgePolice challenge.
